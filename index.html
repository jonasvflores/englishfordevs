📖 What is HTML & CSS?

Introduction to Web Development

Before you start this course, you need to understand what HTML and CSS are. These are the fundamental technologies for creating web pages.

What is HTML?

HTML stands for "HyperText Markup Language". It is the code used to create the structure and content of web pages.

Think of HTML like the skeleton of a body:

<h1>This is a heading</h1> <p>This is a paragraph</p> <button>This is a button</button>

HTML tells the browser: "This is a heading. This is a paragraph. This is a button."

What is CSS?

CSS stands for "Cascading Style Sheets". It is the code used to style and design web pages. CSS controls colors, fonts, spacing, and how elements look.

Think of CSS like the clothes and makeup on a body:

h1 { color: blue; font-size: 24px; } button { background-color: darkblue; color: white; }

CSS tells the browser: "Make this heading blue. Make this button have a dark blue background and white text."

Defines elements (heading, paragraph, button) Defines colors, fonts, spacing A complete web page
Like building a house structure Like painting and decorating the house A finished, decorated house

2. BEFORE YOU START

Make sure that you have:

  • A text editor - Visual Studio Code, Notepad, or another text editor
  • A web browser - Chrome, Firefox, Safari, or Edge
✓ No internet connection is required for this activity.

Optional: Download a Text Editor

If you don't have Visual Studio Code, you can download it for free:

https://code.visualstudio.com/

Or you can use the default text editor on your computer:

  • Windows: Notepad
  • Mac: TextEdit
  • Linux: gedit or nano

3. CREATE THE PROJECT FOLDER

Create a new folder on your computer.

Name the folder:

my-first-web-page

Open the folder. You will use this folder to store the files for your website.

Steps:

  1. Right-click on your desktop or in File Explorer
  2. Select "New Folder" (or "New" → "Folder")
  3. Name it: my-first-web-page
  4. Double-click to open it

4. CREATE THE HTML FILE

Create a new file inside the project folder.

Name the file:

index.html

Make sure that the file extension is:

.html
⚠️ Do not save the file as:
index.html.txt

How to Create the File:

  1. Open your text editor (Notepad, Visual Studio Code, etc.)
  2. Go to File → New File
  3. Go to File → Save As
  4. Name it: index.html
  5. Make sure the folder is: my-first-web-page
  6. Click Save

5. ADD THE HTML STRUCTURE

Open index.html in your text editor.

Enter the following code:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Web Page</title>
</head>

<body>

    <h1>Hello, World!</h1>

    <p>This is my first web page.</p>

</body>
</html>

Save the file.

Understanding the Code:

Code Meaning
<!DOCTYPE html> Tells the browser this is an HTML5 document
<html></html> Container for the entire HTML document
<head></head> Contains information about the page (not visible to users)
<title></title> Title shown in the browser tab
<body></body> Contains the visible content of the page
<h1></h1> Heading (large title)
<p></p> Paragraph (text)

6. OPEN THE PAGE

Open the index.html file in your web browser.

How to Open:

  1. Find your index.html file in File Explorer
  2. Right-click on the file
  3. Select "Open with" → Choose your web browser (Chrome, Firefox, etc.)
  4. Wait for the browser to open

What You Should See:

You should see:

  • Hello, World! (heading)
  • This is my first web page. (paragraph below)
✓ If you can see the text, your HTML page is working!

7. CREATE THE CSS FILE

Return to your project folder.

Create another file and name it:

style.css

Make sure that the file extension is:

.css

Your project should now contain:

my-first-web-page │ ├── index.html └── style.css

How to Create the CSS File:

  1. Open your text editor again
  2. Go to File → New File
  3. Go to File → Save As
  4. Name it: style.css
  5. Make sure the folder is: my-first-web-page
  6. Click Save

8. CONNECT HTML AND CSS

Return to index.html.

Inside the <head> section, add:

<link rel="stylesheet" href="style.css">

Your <head> section should now look like this:

<head>
    <meta charset="UTF-8">
    <title>My First Web Page</title>
    <link rel="stylesheet" href="style.css">
</head>

Save the file.

What This Means:

The line <link rel="stylesheet" href="style.css"> tells the browser:

"Use the file called style.css to style this HTML page."

Without this line, the browser won't apply any CSS styling.

9. ADD YOUR FIRST STYLE

Open style.css.

Enter:

body {
    background-color: lightblue;
    font-family: Arial, sans-serif;
}

h1 {
    color: darkblue;
}

Save the file.

What This Code Means:

Code Meaning
body { } Styling for the entire page body
background-color: lightblue; Make the background light blue
font-family: Arial, sans-serif; Use Arial font (or similar)
h1 { } Styling specifically for h1 headings
color: darkblue; Make the heading text dark blue

10. REFRESH THE PAGE

Return to your browser.

Refresh the page:

  • Press F5 on your keyboard, OR
  • Press Ctrl + R (Windows) or Cmd + R (Mac), OR
  • Click the refresh button in the browser

You should now see a page with:

  • A light blue background
  • A dark blue heading
  • The text from your HTML file

If Something Went Wrong:

Check that:

  • 1. style.css is in the same folder as index.html
  • 2. The file name is exactly style.css
  • 3. The <link> element was added correctly in the <head>
  • 4. Both files were saved

12. ADD A BUTTON

Return to index.html.

Below the paragraph, add:

<button>Click Me</button>

Your <body> should now look like:

<body>
    <h1>Hello, World!</h1>
    <p>This is my first web page.</p>
    <button>Click Me</button>
</body>

Save the file.

Refresh the browser.

You should now see a button on the page.

13. STYLE THE BUTTON

Open style.css.

Add:

button {
    background-color: darkblue;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 6px;
}

Save the file.

Refresh the browser.

The button should now have a different appearance.

What the Code Means:

CSS Property Meaning
background-color: darkblue; Background color of the button
color: white; Text color on the button
padding: 10px 20px; Space inside the button (top/bottom and left/right)
border: none; Remove the button border
border-radius: 6px; Round the corners of the button

14. YOUR FINAL PAGE

Your final project should contain:

my-first-web-page │ ├── index.html └── style.css

Your page should contain:

  • ✓ A heading
  • ✓ A paragraph
  • ✓ A button
  • ✓ A colored background
  • ✓ Customized text
  • ✓ A styled button
Congratulations! You have created your first web page!

15. IF SOMETHING GOES WRONG

The page is blank

Check your HTML code. Make sure the file was saved as:

index.html

The CSS doesn't work

Make sure that the following line exists inside <head>:

<link rel="stylesheet" href="style.css">

The background doesn't change

Make sure that style.css is in the same folder as index.html.

The button doesn't appear

Make sure you added:

<button>Click Me</button>

inside the <body>.

The browser shows the code instead of the page

Check the file extension. The file must be:

index.html

not:

index.html.txt

20. TRANSLATION TRAPS

Some expressions may look strange if translated word by word.

REFRESH

In everyday English:

refresh = refrescar (drink something cold)

In a browser:

refresh = atualizar/recarregar a página

LOAD

In everyday English:

load = carga/carregar peso (carry a heavy weight)

In technology:

load = carregar (bring into the browser)

Example:

The page is loading. = A página está carregando.

DISPLAY

In everyday English:

display = exibição (a show or exhibition)

In technology:

display = exibir/mostrar (show on screen)

Example:

The browser displays the page. = O navegador exibe a página.

STYLE

In everyday English:

style = estilo (fashion or personal style)

In web development:

style = estilizar (apply design/appearance)

Example:

Style the button. = Estilize o botão.

BODY

In everyday English:

body = corpo (human body)

In HTML:

body = corpo da página/seção principal do documento

Example:

Add the button inside the body. = Adicione o botão dentro do body.

HEAD

In everyday English:

head = cabeça (top of your body)

In HTML:

head = seção de informações do documento (metadata section)

Example:

Add the link inside the head. = Adicione o link dentro do head.

34. THE MAIN LESSON

Technical English is not about translating every word.

It is about being able to:

FIND → the information you need

UNDERSTAND → what it means in context

ACT → follow the instructions

CHECK → if your result is correct

You don't need to understand everything.

You need to understand enough to do something.

And when you don't understand something:

  • Use the context.
  • Look for patterns.
  • Use the tools available.
  • Check the result.

The goal is not to work without translators or artificial intelligence.

The goal is to become capable of using these tools intelligently.
