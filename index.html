Inglês Instrumental para Desenvolvedores

O que é Inglês Instrumental?

Como já explicado em aula, o que importa no inglês instrumental não é a tradução literal (nem sempre), nem a conversação fluente. Inglês instrumental é o inglês funcional: a capacidade de extrair informação de um texto em inglês para realizar uma tarefa específica.

Quando você lê uma documentação de programação, não precisa entender cada palavra perfeitamente. Você precisa identificar:

  • O que fazer (ações/verbos)
  • Como fazer (passos, ordem)
  • Onde fazer (arquivos, pastas)
  • Resultado esperado (o que deve acontecer)

Por que isso funciona?

A documentação técnica tem estrutura previsível. Os verbos se repetem, os padrões se repetem, os termos técnicos aparecem sempre da mesma forma. Você não está aprendendo inglês; está aprendendo a navegar um contexto específico em inglês.

Muitas palavras você nem precisa traduzir: file, button, CSS, HTML fazem sentido no contexto da programação. Você as reconhece, não as traduz.

Objetivo deste curso

Este curso foi desenvolvido para praticar exatamente isso. Você vai trabalhar com a documentação que preparei, baseada em exemplos reais de aula, e aprender a:

  • Identificar instruções sem traduzir tudo
  • Reconhecer quando é importante entender uma palavra
  • Diferenciar informação essencial de contexto
  • Usar pistas (código, contexto, repetição) para entender

What is HTML & CSS?

HTML

HTML stands for "HyperText Markup Language". It is the code used to create the structure and content of web pages.

<h1>This is a heading</h1> <p>This is a paragraph</p> <button>This is a button</button>

CSS

CSS stands for "Cascading Style Sheets". It is the code used to style and design web pages.

h1 { color: blue; font-size: 24px; }

HTML + CSS Together

HTML CSS Result
Creates structure Styles appearance A complete web page

Translation Traps

REFRESH

Everyday English: To drink something cold

In a browser: To reload the page

Refresh the page = Atualize/recarregue a página

LOAD

Everyday English: To carry a heavy weight

In technology: To bring into the browser

The page is loading = A página está carregando

DISPLAY

Everyday English: An exhibition

In technology: To show on screen

Display the page = Exiba a página

STYLE

Everyday English: Fashion or personal style

In web development: To apply design

Style the button = Estilize o botão

BODY

Everyday English: Human body

In HTML: Main section of the document

Inside the body = Dentro do body
